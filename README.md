# 资金账本 · my-assets

面向手机的本地资产账本。支持日元和人民币余额、负债、历史快照与 JSON 备份；无需账户或后端，资产数据保存在本机浏览器中。当前页面版本为 **3.4**。

## 使用

- 点右下角猫咪添加资产，填写来源和**当前余额**（不是本次增减额）。两种币种均输入整数，负数表示负债；同一币种下来源名称不能重复。
- 右上角切换日元／人民币，同时切换首页折算币种和新增资产的默认币种，已有资产仍保留原币。
- 资产明细分为名称、币种金额、较上次记录的变化三栏，统一白字；点整行修改。排序可选默认更新顺序、名称拼音升序或降序。
- 金额变化按红涨绿跌显示；资产余额正数保持原色，负数显示绿色。首页和历史页使用相同配色。
- 人民币首页总资产下方显示「投资」与「出借」；日元首页隐藏这两行，同时保留卡片高度。来源**恰好等于**「投资本金」「投资现金」的余额用于投资收益率 `(投资现金－投资本金) ÷ 投资本金`；盈利红色、亏损绿色，本金不存在或不大于零时显示「—」。其他名称**包含**「投资」的资产汇总为出借，不计算盈亏。
- 投资本金、投资现金和出借项保留在资产明细及备份中，但不计入首页与历史的总资产、实际资产及变化统计。
- 更新或删除资产会保存当天最后一次快照。历史曲线只显示实际记录的日期，漏记日期不补齐；可修正历史金额。资产日历的「重置」经确认后删除旧快照，以当天余额作为新起点。
- 汇率来自 [Frankfurter](https://frankfurter.dev/)，是参考价，不是实时交易价。缺少必要汇率时跨币种金额显示「待汇率」；历史快照使用保存当时的汇率，不随之后报价重算。

## 数据与备份

在设置中定期导出 `我的资金-完整备份.json`。导入会覆盖本应用当前的全部资产和历史；旧版 `my-assets` 备份仍可导入，收支账本 `my-ledger` 的备份不能导入。资产数据不会上传 GitHub，也不会跨设备同步。清除网站数据可能删除本地账本；两个应用共用 GitHub Pages 域名，请分别备份。

## 开发与发布

需要 Node.js 22.18+：

```sh
npm ci
npm run dev
npm run build
```

开发和 GitHub Pages 路径均包含 `/my-assets/`。仓库 `main` 分支推送后，`.github/workflows/deploy.yml` 使用 GitHub Actions 构建并发布；仓库 Settings → Pages → Source 需设为 GitHub Actions。手机可用 Safari 打开 `https://gsmhkor.github.io/my-assets/`，通过“分享 → 添加到主屏幕”安装。

`package.json` 使用有效的三段式版本 `3.4.0`，页面显示时省略末尾 `.0`。应用安装名称固定为「资金账本」。

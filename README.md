# 资金账本 · my-assets

面向手机的本地资产账本。支持日元和人民币余额、负债、历史快照与 JSON 备份；无需账户或后端，资产数据保存在本机浏览器中。当前页面版本为 **3.5**。

## 使用

- 点右下角猫咪添加资产，填写来源和**当前余额**（不是本次增减额）。两种币种均输入整数，负数表示负债；同一币种下来源名称不能重复。
- 右上角切换日元／人民币，同时切换首页折算币种和新增资产的默认币种，已有资产仍保留原币。
- 资产明细以浅色卡片分为名称、币种金额、较上次记录的变化三栏，用横线分行；点整行修改。圆角按钮可在名称拼音升序和降序之间切换，默认升序。
- 在页面顶端下拉可检查应用更新，效果与设置页的“更新”按钮相同，不保存历史快照。资产明细中间栏的币种和金额一起左对齐。
- 金额变化按红涨绿跌显示；资产明细的余额均用原色，首页和历史页的负余额显示绿色。
- 人民币首页总资产下方显示「投资」与「出借」；日元首页隐藏这两行，同时保留卡片高度。来源**恰好等于**「投资本金」「投资现金」的余额用于投资收益率 `(投资现金－投资本金) ÷ 投资本金`；盈利红色、亏损绿色，本金不存在或不大于零时显示「—」。其他名称**包含**「投资」的资产汇总为出借，不计算盈亏。
- 投资本金、投资现金和出借项保留在资产明细及备份中，但不计入首页与历史的总资产、实际资产及变化统计。
- 更新或删除资产会保存当天最后一次快照。已有账本在打开应用、回到前台、恢复联网时检查当天快照；前台每 30 秒检查跨天，即使余额未变也会保存新一天。应用关闭或被系统暂停时无法后台保存，下次打开只保存当天，不补造漏记日期。历史金额仍可修正；资产日历的「重置」经确认后删除旧快照，以当天余额作为新起点。
- 汇率来自 [Frankfurter](https://frankfurter.dev/)，是参考价，不是实时交易价。今天的历史总额与首页使用当前汇率，获取到当日报价后也同步保存今日快照。跨天后按历史日期查询并固定上一天的汇率；快照保存与历史折算只接受报价日期与快照日期一致的汇率，不使用今天或其他日期的报价替代。断网先保存原币余额，历史汇率查询失败后重试；报价延迟发布时每 15 分钟复查，日期再过去一天后复查并固定结果。没有当日报价（如休市日）时显示「待汇率」，原币余额仍完整保留。

## 数据与备份

在设置中定期导出 `我的资金-完整备份.json`。导入会覆盖本应用当前的全部资产和历史；旧版 `my-assets` 备份仍可导入，收支账本 `my-ledger` 的备份不能导入。资产数据不会上传 GitHub，也不会跨设备同步。清除网站数据可能删除本地账本；两个应用共用 GitHub Pages 域名，请分别备份。

## 开发与发布

需要 Node.js 22.18+：

```sh
npm ci
npm run dev
npm run build
```

开发和 GitHub Pages 路径均包含 `/my-assets/`。仓库 `main` 分支推送后，`.github/workflows/deploy.yml` 使用 GitHub Actions 构建并发布；仓库 Settings → Pages → Source 需设为 GitHub Actions。手机可用 Safari 打开 `https://gsmhkor.github.io/my-assets/`，通过“分享 → 添加到主屏幕”安装。

`package.json` 使用有效的三段式版本 `3.5.0`，页面显示时省略末尾 `.0`。应用安装名称固定为「资金账本」。

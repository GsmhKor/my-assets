# 视觉与素材

沿用用户现有 `my-ledger` 的猫咪图片与奶油色卡片。3.9 使用 CSS 多层渐变绘制固定金属质感壁纸：浅色模式以白色、银灰与冷铂色为主，深色模式以黑色、石墨灰与钛银色为主，通过宽幅斜向亮带形成光泽；资产明细保留横线和暖米色名称。1.8.0 按用户要求编辑新安装图标的蓝色背景，其余猫咪画作沿用现有素材。

4.0 深色模式统一采用钛灰底色与米金点缀：总资产和普通卡片共用 `#2B313B` 底色、边框与阴影，导航和输入框 `#242A33`，分隔线 `#424B58`，主要文字 `#EEE8DC`，条目名称和强调色 `#DFC99D`，次要说明 `#AFB6C0`。总资产背景图以 7% 不透明度柔光叠加为水印；卡片、编辑框和导航的外边框使用半透明 `#424B5880`，内部横线保持原样。页面背景压暗为炭黑渐变和微弱银色反光，与卡片区分层次。涨跌保留红绿，浅色配色保持不变。

- `balance-hydrangea.png`：资产卡片背景。
- 4.1 设置页主题按钮依次切换「浅色 → 深色 → 定制」，记住所选主题，无有效偏好时默认定制。「定制」采用《暗黑破坏神 2》旧石材与铜框风格的偏亮方案：浅砂岩背景 #B5A68E、羊皮纸色石板卡片、旧铜描边、压边阴影与 14px 圆角。名称使用深古金 #573E1E、金额深褐 #3B3023、强调色 #402B13、说明文字 #4E4232；红绿变化同步加深以适应浅底。定制主题的总资产背景图以 18% 不透明度正常叠加，呈现原图色彩。重置按钮单独采用铜棕底色与压边，保持操作及确认逻辑。所有主题共用相同字体、字号、字重与字距，定制仅调整配色与材质。浏览器栏与原生控件采用浅色方案同步，已有浅色和深色偏好仍保留。
- `antique-grain.svg`：CSS 背景使用的细颗粒纹理，以 SVG 分形噪声生成，用于定制主题的石材层次，无外部图片请求。
- 4.2 定制背景稍微压深为烟晶色 `#9E907D`，以 `smoky-quartz-hex.svg` 平铺六边形宝石切面：宽阔台面、六面斜边、低对比明暗与细颗粒形成柔和晶石质感，不使用大幅金属反光。背景固定，不随滚动移动；卡片沿用浅色石材以保持阅读层次，背景上的强调文字加深为 `#302313`，浏览器栏同步新底色。
- 4.3 按用户最终要求改为偏暗的金属金背景，移除六边形素材与几何切面。背景以古金色 `#A58A3E` 为基调，使用连续的斜向明暗渐变和柔和宽幅反光表现金属光泽，`antique-gold-grain.svg` 柔光叠加参考图中的细颗粒质感。背景固定，渐变铺满视口，只有细颗粒重复平铺；背景文字强调色加深为 `#21170B`，浏览器栏使用古金底色。卡片继续使用原有浅石材，纹理通过原生 SVG 和 CSS 生成，无外部图片请求。
- iPhone 主屏幕应用启用 `apple-mobile-web-app-status-bar-style=black-translucent`，配合已有的 `viewport-fit=cover`，允许背景延伸至灵动岛周围的状态栏区域；页面继续通过 `safe-area-inset-top` 为内容留出空间。`theme-color` 仅提供系统界面的纯色提示，不能携带金属纹理；Safari 浏览器自身界面及不同 iOS 版本的系统叠层仍由系统绘制。
- 4.3 彩虹方案：按用户最新要求，定制主题采用光滑亮面的深色全息彩虹金属，移除颗粒纹理素材。午夜蓝 `#111522` 底色上，以蓝、青、绿、少量暖色、玫红和紫色的连续斜向色带，叠加清晰而柔和的冷白反光；背景静止、无六边形或几何拼块。卡片使用冷色深蓝灰渐变，上缘浅色高光、下缘暗边及分层投影带来轻微立体感；按钮具有凸起边缘和按下反馈，输入框呈浅凹陷。浅紫强调和冰青名称配浅白正文，涨跌保持红绿；浏览器栏和原生控件同步深色方案，保留 iPhone 透明状态栏设置。
- 4.4 定制背景更换为原创彩虹砖墙 `rainbow-brick-v4.4.webp`，只借鉴用户参考图的色彩与砖墙氛围：错缝横砖、凹陷砖缝和侧上方反光形成真实层次，蓝紫与青绿为主，局部暖色与玫红过渡。背景固定居中覆盖视口，叠加深色渐变保证标题可读；沿用深色立体卡片及 iPhone 透明状态栏设置。素材由内置 imagegen 生成，WebP 仅作压缩；完整提示词见 `source/rainbow-brick-v4.4-prompt.md`。
- 4.4「默认」排序与「重置」按钮共享 64×44px 外尺寸、12px 字号、600 字重、统一内边距和对齐方式；浅色/深色模式采用 22px 圆角，定制模式均为 12px，保留各自原有操作和色彩。
- 4.5 总资产卡片新增 `balance-hydrangea-dark-v4.5.webp`，由内置 imagegen 基于原始 `balance-hydrangea.png` 编辑生成，保留绣球花、猫咪及构图，以深蓝纸底、蓝紫花瓣、冰青/淡紫轮廓适配深色。深色与彩虹主题使用新版，68% 不透明度正常叠加，并通过纵向遮罩减弱顶部和底部细节，保证金额及小字可读；浅色模式沿用原图。卡片原有底色与布局保留。完整提示词见 `source/balance-hydrangea-dark-v4.5-prompt.md`。
- 4.5 设置页主题名称由「定制」改为「彩虹」，当前标签、切换提示和无障碍名称同步更新；内部存储仍使用 `custom`，已保存的主题偏好继续有效。
